# Правила для агентов — сайт denisdaragan.com

> Один файл на всех. Claude читает его через `CLAUDE.md` (`@AGENTS.md`), Codex — напрямую.
> Правки правил — только сюда, чтобы у двух агентов не разошлись версии.
> Карта кода и состояние — `HANDOFF.md` (вверху — блок «Состояние»).
>
> Это репозиторий сайта: оболочка и страницы, портфолио `/landscape/`, SEO,
> выкладка на GitHub Pages. Редактор, приложение OUROBOROS, лаборатория,
> рендер и инструменты проектов с 30.09.2026 живут отдельно — в папке
> `../Ouroboros-Editor` (закрытый репозиторий `DenisDaraganGarden/ouroboros-editor`).
> Главная сцена сайта приходит оттуда, здесь её не правят (§5).

## 1. Кто и как

- Общение с Денисом — по-русски. Денис — художник, не программист: технические
  решения агент принимает сам, спрашивает только про художественное.
- Интерфейс сайта и портфолио (стиль, расположение, подписи) не менять без
  прямой просьбы. Новые элементы — в существующем стиле, с подписями RU и EN.
- `git push` — только по просьбе. `main` на GitHub — мастерская: слияние в
  него сайт не меняет. Сайт (GitHub Pages) собирается из `main` только по
  кнопке «На сайт» в редакторе OUROBOROS (коммит `chore(home): publish
  authored scene`) или вручную: Actions → Deploy GitHub Pages → Run
  workflow — и то и другое по просьбе Дениса.
- Этот репозиторий открытый. Адреса и порты серверов, ключи, настройки шлюза
  и туннелей сюда не класть. CMS (Payload) и серверные настройки — в закрытом
  `DenisDaraganGarden/ddg-content-platform`; здесь только контракт манифеста
  портфолио (`schemas/portfolio-manifest.schema.json`,
  `src/features/portfolio-content/`, резерв `public/content/`). Пароль и
  оригинал PDF портфолио — только в локальной Git metadata
  (`landscape-private`), в репозиторий не класть.
- Проверки в обычной работе — по просьбе Дениса. Перед push — минимум
  `npm run lint && npm run build`, перед push кода — ещё `npm run check:fast`
  (то же гоняет GitHub). Сайт выкладывается только после них
  (`deploy-pages.yml`).

## 2. Начало сессии — знать состояние

```bash
npm run handoff
```

Печатает ветку и последний коммит, отставание от `origin/main`, незакоммиченное,
stash, ветки с незалитыми коммитами, воркдеревья и занятые порты.

Прежде чем решить, что что-то «пропало» или «не сделано», проверить все места,
где может лежать работа: `git log --oneline main..origin/main`, `git branch --no-merged main`,
`git worktree list` (воркдеревья Codex — `.claude/worktrees/*`), `git stash list`.

## 3. Конец сессии — оставить след

- Закоммитить работу или явно оставить незакоммиченной — и в обоих случаях
  обновить блок «Состояние» в начале `HANDOFF.md`: последний коммит, что не
  закоммичено, что дальше. «Состояние» — только то, что верно сейчас, а не
  дневник: свою запись переписать, отжившую перенести в
  `docs/archive/handoff-log-2026.md`.
- Работа в воркдереве не считается сделанной, пока не слита в `main` или не
  описана в «Состоянии».
- Временные скрипты, скриншоты и заметки удалить; перед коммитом посмотреть
  `git status`, чтобы в публичный репозиторий не ушло лишнее.

## 4. Порты

Записи — в `.claude/launch.json` с `cwd: "."`. Порты не переименовывать и не
перенумеровывать без прямой просьбы.

| Запись | Порт | Что это | Чьё |
|---|---|---|---|
| `site` | **41211** | dev-сервер сайта, главная `/` | Дениса — смотреть его глазами |
| `dist` | **41214** | `vite preview` собранного `dist/` | Общий, только чтение |
| `cms` | **41216** | CMS портфолио (из `ddg-content-platform`) | Дениса |
| `portfolio` | **41217** | редактор превью портфолио `/portfolio/edit` | Дениса |
| `landscape` | **41218** | редактор портфолио `/landscape/` (`scripts/landscape/editor.mjs`) | Дениса — пишет в `public/landscape` и `src/data/landscapePortfolio.json` |
| — | 4173 | внутренний порт смоук-теста (`SMOKE_PORT`) | Никогда не занимать вручную |

Порты редактора (41212, 41213, 41215, 41219) — в `../Ouroboros-Editor`.
Агент проверяет сайт из свежего профиля Playwright на своём порту; в 41211
заходит только смотреть. Смоук-тест требует машину целиком: перед
`npm run smoke` остановить dev-серверы.

## 5. Главная сцена — копия из OUROBOROS

- Файлы, перечисленные в `.ouroboros-sync.json` (рендер, сцена, звук,
  `useLanguage`, папки `public/models`, `textures`, `hdri`, `audio`), — копия
  движка. Здесь их не правят: правка уходит в `../Ouroboros-Editor`, а на сайт
  попадает кнопкой «На сайт» в редакторе. Скрипт копии — `scripts/siteSync.mjs`
  там; он же убирает файлы, которых в сцене больше нет.
- Своё у сайта: оболочка `src/App.jsx`, `src/main.jsx`, навигация и страницы,
  словарь `src/i18n/translations.js` и провайдер языка, контент и превью
  портфолио, статическое портфолио `public/landscape`, SEO, выкладка.
- Подписи, которые сцена берёт через `t('…')`, живут в словаре сайта. Движок
  при публикации сообщает, если какой-то нет.
- Проверки рендера (вода, свет, тени, растения) — в репозитории движка.
