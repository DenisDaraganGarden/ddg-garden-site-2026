# Правила запуска — порты и владение

> Общение с Денисом — по-русски. Карта кода — в `HANDOFF.md`, прочитай его тоже.

## Карта портов

Номера выбраны из незанятого диапазона (412xx): ни один известный сервис и ни один
дефолт инструментов (3000, 5173, 8080…) сюда не садится, случайная коллизия
практически исключена. Все записи — в `.claude/launch.json` с `cwd: "."`, так что
работают из любого чекаута, включая воркдеревья.

| Запись | Порт | Что это | Чьё |
|---|---|---|---|
| `site` | **41211** | dev-сервер, главная `/` | **Дениса** — смотреть его глазами |
| `editor` | **41212** | dev-сервер, `/` ведёт в `/home/edit` | **Дениса** — здесь его черновик |
| `sandbox` | **41213** | тот же редактор, отдельный origin | **Нейронки/агента** — здесь можно ломать |
| `dist` | **41214** | `vite preview` собранного `dist/` | Общий, только чтение |
| `lab` | **41215** | лаборатория ассетов `asset-lab.html` | Общий: смотреть и крутить ползунки можно всем, черновика сцены тут нет |
| — | 4173 | внутренний порт смоук-теста (`SMOKE_PORT`) | Никогда не занимать вручную |

## Законы

1. **Порт = origin = черновик.** Черновик сцены живёт в `localStorage`, а он
   пер-origin. Разные порты — физически разные черновики. Поэтому песочнице
   не нужно разрешение, чтобы не испортить черновик Дениса — она не может.
2. **Агент работает только в `sandbox` (41213)** или через свежий профиль
   Playwright (у него свой origin-storage, любой порт безопасен). В 41211/41212
   агент заходит только смотреть, не трогая ползунки.
3. **Порты не переименовывать и не перенумеровывать без прямой просьбы** —
   к ним привязаны кнопки запуска и черновики.
4. **Обмен сценой — только через публикацию**: «На главную» пишет
   `publishedHomeSceneSettings.js`, Денис забирает кнопкой «Взять опубликованные».
   Никогда не через копирование localStorage. «На сайт» делает то же и сразу
   коммитит файл и пушит `HEAD:main` на GitHub — дальше Pages собирает сам.
   Агент в песочнице «На сайт» не нажимает без просьбы: это живой сайт.
5. **Смоук-тест требует машину целиком**: перед `npm run smoke` остановить все
   dev-серверы. «Не видно» при работающих серверах — это конкуренция за GPU,
   а не регрессия.
7. **Сервер редактора живёт кодом на момент старта.** `vite.config.js` (endpoint
   публикации и «На сайт») и список ключей `publishedHomeSceneKeys.js` он читает
   один раз. После коммитов, которые их меняют, перезапустить `editor` кнопкой
   запуска и перезагрузить вкладку — иначе публикация уйдёт со старым набором ключей.
6. Порт для теста на телефоне (`npm run dev:lan`) — тот же 41211:
   `http://<адрес-мака>:41211/?hud=1`.

## Миграция со старых портов (7311 / 7312 / 4199)

Черновики, набитые до перенумерации, остались на старых origin. Если там было
несохранённое: поднять старый порт один раз —

```bash
npx vite --config vite.editor.config.js --port 7312 --strictPort
```

— открыть `/home/edit`, нажать **Publish**, погасить сервер, и на новом порту
нажать «Взять опубликованные». После этого старые origin можно забыть.
