# Текстуры по ИИ и библиотека материалов (2026-09-25)

> Просьба Дениса: «правой кнопкой по объекту из SketchUp — сгенерировать или
> доработать текстуру: аналог (хоть с Pinterest), описание, контекст; карты
> PBR одна за другой без расхождений; бесшовная по умолчанию; размер плитки,
> качество, разрешение, число вариантов; ключ OpenAI вставить один раз;
> материалы — в библиотеку».

## Как пользоваться

1. «Настройки движка» (шестерёнка) → «API»: вставить ключ OpenAI (⌘V) → «Сохранить».
   Ключ ложится в связку ключей macOS (не в проект, не в git, не в браузер).
2. Правый щелчок по модели SketchUp → «Сгенерировать / доработать текстуру…».
   Окно не модальное: модель под ним можно крутить.
   - **Аналоги** — ⌘V, перетащить или «+» (до 12); уходят только в OpenAI, нигде не хранятся.
   - **Сейчас** — текущая текстура материала SketchUp и её размер в метрах.
   - **Что я хочу** — описание на любом языке.
   - **Кадр сцены как контекст** — снимок вида, где материал стоит.
   - «Улучшить текущую · ИИ» — по текстуре SketchUp; «Только добавить карты» —
     без ИИ и без денег: к текстуре SketchUp рельеф, нормали, AO, шероховатость;
     «Сгенерировать с нуля» — по описанию и аналогам.
   - Модель (из списка ключа, по умолчанию gpt-image-2.5-sunburst), качество
     (до xhigh/max у 2.5), разрешение 1024–2048, вариантов 1–4, плитка в метрах.
3. Варианты показаны плиткой 2×2 (шов виден сразу) → «Применить»: шов
   перерисовывается, считаются карты, материал ложится в библиотеку и на модель —
   во всей модели, как в SketchUp.
4. «На модели»: раскладка (как в SketchUp / прямо по граням), плитка, рельеф,
   матовость, «Вернуть материал SketchUp». Библиотека — внизу окна, общая для всех проектов.

## Как устроено

- **ИИ рисует только цвет (альбедо).** Рельеф, нормали (OpenGL, как у three.js),
  AO и шероховатость считаются из него попиксельно (`scripts/materialMaps.mjs`),
  поэтому все карты совпадают пиксель в пиксель — вторая генерация нарисовала
  бы доски и швы чуть иначе. Соседи через край берутся с другой стороны плитки.
- **Бесшовность:** задание модели всегда требует бесшовную плитку, ровный свет и
  масштаб «квадрат = N м». Затем картинка сдвигается на полплитки, модель по маске
  перерисовывает крест шва, и в картинку вклеивается только этот крест — маска у
  GPT Image лишь подсказка, остальное остаётся пиксель в пиксель. Не вышло —
  шов сшивается на месте (`blendSeams`).
- **Сервер** (`scripts/materials.mjs`, `scripts/openaiKey.mjs`): `/__openai/key`,
  `/__openai/models`, `/__materials/generate|finish|maps`, `/__library/materials`.
  Маршруты, что тратят деньги, отвечают только своему адресу (localhost) и JSON.
- **Библиотека:** `~/Ouroboros/library/materials/<id>/` — `material.json`
  (имя, плитка, модель, описание, шов), `albedo.webp`, `normal.png`,
  `roughness.webp`, `ao.webp`, `height.png`, `preview.webp`; черновики вариантов —
  `.drafts/`, живут сутки.
- **Проект:** `modelMaterials` {объект: {имя материала SketchUp: {material, tile,
  normal, roughness, projection?}}} — одно на все камеры, на сайт не уходит.
  Сцена (`src/materials/modelMaterials.js`) меняет карты на клонах материалов
  модели; координаты текстуры SketchUp сохраняются, плитка считается по их
  масштабу (∂P/∂u, ∂P/∂v); грани без координат и раскладка «прямо по граням»
  получают проекцию на плоскости модели (стены — картинкой вверх).
- **Проверки:** `npm run check:ai-materials` — математика карт и весь путь на
  поддельном OpenAI (без ключа и без денег).

## Агенту

- Ключ не читать и не вставлять: его вставляет Денис в «API». Для проверок —
  `OPENAI_API_KEY` и `DDG_OPENAI_BASE_URL` на поддельный сервер (как в проверке).
- Материалы библиотеки — обычные файлы: карты можно пересчитать из `albedo.webp`
  теми же функциями `materialMaps.mjs`; имя — в `material.json`.
