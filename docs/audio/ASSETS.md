# Soundscape source ledger

The environmental and UI recordings in `public/audio/soundscape/` are Freesound
high-quality MP3 previews of real field/foley recordings. Each source page marked
the work **Creative Commons 0** when it was selected on 2026-08-30. CC0 permits
copying, modification, redistribution and commercial use without attribution.
Credits are retained here anyway so every shipped sound remains traceable.

The original WAV/FLAC masters require a free Freesound login. Keep them as the
archival source when the final production master is assembled; the checked-in
48 kHz ~180 kbps derivatives are deliberately browser-sized audition files.

## Existing music warning

`portfolio/VOCES8 & Samuel Barber - Barber Agnus Dei.mp3` predates this sound
laboratory. No license, purchase receipt, or publication clearance is recorded
in the repository. The new mixer keeps it available as the legacy **Music** mode
because the brief explicitly asks to preserve that choice, but this file must not
be treated as cleared for a public deployment until its rights are verified.
