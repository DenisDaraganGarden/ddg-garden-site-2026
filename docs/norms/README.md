# Нормы — библиотека (черновик)

Тексты норм, на которые опирается движок: агент ищет по ним сам (`grep`),
Денис может читать. Пока — просто файлы в репозитории; потом библиотека
станет разделом движка: оглавление, поиск, ссылки из инструментов прямо на
пункт («Инсоляция» → табл. 5.58–5.60), своя вёрстка.

Официальные документы государственных органов — не объекты авторского
права (ГК РФ, ст. 1259, п. 6), поэтому их тексты лежат в открытом
репозитории.

## Чего не хватает

- ГОСТ Р 57795-2017 «Здания и сооружения. Методы расчёта продолжительности
  инсоляции» — как именно считать (дата расчёта в периоде, с какой высоты
  солнца, как складывать прерывистую инсоляцию). Нужен для инсоляции в
  «Участке».
- СП 42.13330 (градостроительство) и нормы озеленения — по мере надобности.

## Как пользоваться агенту

- Найти пункт: `grep -n -i "инсоляц" docs/norms/sanpin-1.2.3685-21.txt`,
  затем читать страницу целиком (`sed -n`), а не одну строку: таблицы
  распознаны по строкам и перемешаны.
- Число из OCR в код или в отчёт — только после вычитки; если есть
  выписка (`insolation.md`), брать из неё и ссылаться на пункт и таблицу.
