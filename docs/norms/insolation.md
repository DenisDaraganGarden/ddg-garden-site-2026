# Инсоляция — выписка из СанПиН 1.2.3685-21

Источник: `sanpin-1.2.3685-21.txt`, страницы PDF 355–356, п. 165–168,
таблицы 5.58–5.60. Текст распознан (OCR) и вычитан вручную; таблицы в OCR
разорваны по строкам, поэтому ячейки собраны по смыслу. Где OCR дал мусор,
в скобках — как прочитано и почему. Перед ссылкой в документах для
заказчика — сверить с официальной действующей редакцией.

## Пункты

- **165.** Расчёт продолжительности инсоляции выполняется по инсоляционным
  графикам или по солнечным картам.
- **166.** Допускается прерывистость инсоляции, при которой один из периодов
  должен быть не менее 1 ч. При этом суммарная продолжительность нормируемой
  инсоляции должна увеличиваться на 0,5 ч соответственно для каждой зоны
  (табл. 5.58).
- **167.** Инсоляция помещений детских домов, домов ребёнка, школ-интернатов,
  лесных школ, школ-санаториев определяется набором помещений
  соответствующего функционального назначения.
- **168.** Допускается отсутствие инсоляции в учебных кабинетах информатики,
  физики, химии, рисования и черчения.
