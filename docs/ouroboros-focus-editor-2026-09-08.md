# Ouroboros: редактор «Фокус»

Выбранный HTML-эскиз перенесён в настоящий `/home/edit`. Старая нижняя панель
заменена одним компактным интерфейсом: шесть рабочих областей слева, список
объектов по запросу, параметры справа, инструменты в кадре и лента камер снизу.
Основная среда после интеграции: http://localhost:41212/home/edit.

## Что работает

- Все существующие разделы используют прежние параметры и команды сцены.
  Добавлены устойчивые идентификаторы контролов для поиска и избранного.
- 15 цветов значков: ПКМ на группе/объекте, ЛКМ или ПКМ на значке инспектора.
  Цвет группы наследуется объектами; индивидуальная метка и её сброс поддерживаются.
- Инспектор 280–420 px: перетаскивание края, клик по корешку для сворачивания,
  открытие с правого края. Строки параметров — 27 px.
- Числа: ЛКМ + горизонтальное движение, Shift для точного шага, Escape для отмены,
  точный ввод. Пустое поле не отправляет NaN в сцену; Enter/blur проверяют диапазон.
- Избранное работает между разделами, для звуковых дорожек и параметров рамки.
  Поиск по словам, названиям и ключам; переход к найденному полю. RU/EN и reload
  не меняют идентичность закреплённых параметров.
- Отмена/повтор параметров ограничены выбранной камерой и форматом. История
  восстанавливает только изменённые поля через прежний setter, сохраняя новые
  имена и другие изменения каталога камер. История не сохраняется после reload.
- Рабочие камеры и сцены разделены. Переименование, включение, порядок,
  длительность и захват используют существующие callbacks. Desktop и Mobile
  сохраняют прежний контракт. Основная рабочая и последняя обычная защищены.
- Лента прокручивается колесом, трекпадом и перетаскиванием; drag не выбирает камеру.
  Миниатюры появляются по мере просмотра камер. Явный захват обновляет ракурс и
  миниатюру; автоматическая миниатюра ничего не записывает в снимок сцены.
- Поиск, справка, G/R/S, режим обзора, Tab для скрытия панелей и предпросмотр
  рамки сайта проверены. Сохранение и публикация остаются прежними действиями
  через отдельные диалоги с понятной областью записи.

## Хранение и границы

Интерфейс: `ddg_focus_editor_ui_v1`; цвета: `ddg_focus_ui_colors_v1`;
миниатюры: `ddg_home_editor_camera_thumbnails_v1`. Это отдельные локальные
данные интерфейса, не часть опубликованных камер.

`ScenePostProcessing` получил только одноразовый запрос снимка после окончательного
вывода кадра. WebP до 320 px создаётся при запросе; постоянный
`preserveDrawingBuffer`, дополнительный проход рендера и настройки качества не
добавлены. Прежний setter продолжает синхронизировать полный снимок активной камеры.

Авторский `publishedHomeSceneSettings.js` не изменён. SHA-256:
`eb46fd506bde15aa961119827b63129b2a9f2de1783ad16612ca266d6955856e`.
Публикации, push и копирования localStorage между origin не было.

## Проверка

Свежие изолированные профили Playwright, sandbox 41213:

- Water extent 82 → 87, undo 82, redo 87, отмена нового жеста оставляет 87.
- Рамка 18% → 21%, undo 18%; избранное доступно после сворачивания/смены раздела.
- Громкость дорожки 0.28 → 0.33 из избранного; значение остаётся в дорожке,
  после EN/reload и при переходе из поиска.
- Пустой numeric input + blur возвращает прежнее значение без изменения сцены;
  точный ввод и Escape во время drag работают.
- Палитра: 15 цветов, наследование, override/reset, клавиатура и возврат фокуса.
- 1440×900, 1280 px и 900×700: инспектор, корешок и лента без горизонтального
  переполнения. На 900 px лента имеет реальное горизонтальное прокручивание.
- В рабочем режиме активна только рабочая карточка. Диалог камеры немедленно
  отражает имя, enabled и 12.5 секунды; G/Space из диалога не управляют сценой.
- Непустой реальный WebGL capture, после уменьшения 320×316; разные ключи
  Desktop/Mobile. Автоматические миниатюры появляются после выбора камеры.
- Предпросмотр сайта и возврат; просмотр/отмена диалога публикации без публикации.
- Lint: 0 ошибок, одно прежнее предупреждение `CoastRocksPBR`.
  В sandbox из проверки исключён только его временный Vite cache.
- Build/SEO проходят; остаётся прежнее предупреждение о крупных чанках.

В свежем профиле опубликованная стартовая камера чёрно-белая (`filmStock=bw`).
Предупреждения WebGL о texture/sampler mismatch воспроизводятся также на исходном
main 41212 до изменений интерфейса; новых JavaScript/React ошибок не обнаружено.
Это не проверка физического iPhone/iPad или полного smoke-сценария.

Исходный HTML-эскиз остаётся в `docs/design/ouroboros-ui-study-2026-09-08/` в
основной рабочей папке. Файлы эскиза и ранее незакоммиченный HANDOFF не включены
в кодовый коммит этой интеграции.
