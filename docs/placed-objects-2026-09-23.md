# Расстановка — объекты библиотеки поштучно, 23 сентября 2026

Дерево, куст и камень, поставленные рукой: по одному, каждый со своими
параметрами генерации и своим местом. Это те же генераторы, что и у
популяций (`treeModel`, `oleasterModel`, `terrainRocks`), только без
размножения — как стриженая изгородь, но без кисти.

## Модель

`src/placed/settings.js`: `placedObjects: [{ id, name, kind, species, x, y, z,
rotation, scale, seed, …ручки вида }]`, `placedEnabled`. Виды: `tree`
(`species` из `TREE_KINDS`: лох, гребенщик, алыча, вяз, ива, сухостой; ручки
высота, ширина кроны, наклон, кручение, плотность, размер листа, сухие
ветви, просвечивание), `shrub` (лох; высота, ширина, плотность, размер
листа, сухость, просвечивание), `rock` (известняк, ракушечник, окатанный;
размер, приплюснутость, вытянутость, форма 0…5, наклон). Не больше 48
объектов. Смена вида дерева подставляет ручки из таблицы вида
(`placedSpeciesDefaults`). Проверка — `node src/placed/settings.check.js`
(входит в `check:editor`). Ключи входят в нормализацию, публикацию и
снимки камер через `DEFAULT_PLACED_SETTINGS`.

## Рендер

`src/placed/PlacedObjects.jsx`: дерево и куст — `PlantPopulation` с одной
посадкой в мировых координатах (свой `makeCoastTree` / `makeOleaster`, свой
атлас коры по виду, ветер и экология — из ассетов сцены `treeAsset` /
`shrubAsset`); камень — один меш `makeRockGeometry` с материалами
`useCoastRockMaterials`, сидит на земле по нижней вершине. Якорь
`placed-<id>` — пустой объект в месте объекта: за него держится манипулятор
и на него наводится камера; визуал `placed-visual-<id>` несёт
`userData.placedId`, по нему клик в сцене выбирает объект
(`sceneHitForObject3D`). Выбранный обведён кольцом у основания.

## Редактор

Узел «Объекты → Расстановка» (`sections/placed.jsx`, хук
`usePlacedEditor`): кнопки «+ Дерево / + Куст / + Камень» ставят объект в
точку, куда смотрит камера (`capturePose().cameraTarget`), сажают на землю
по `createTerrainQuery(...).heightAt` и отступают на 2.5 м, если там уже
стоит объект. Выбор в списке или кликом в сцене; перенос, поворот и масштаб
теми же инструментами, что у лодки (правило манипулятора `placed:` в
`EditorGizmo`: XYZ, поворот вокруг Y, равномерный масштаб); «Показать»,
«На землю», «Дублировать», «Удалить». Всё идёт через историю — отмена
работает и для расстановки.

## Ограничения

Каждое дерево — свой `PlantPopulation` с запеканием импостора (256 px), при
48 объектах это заметно на старте; рыбы, чайки, кувшинки и водоросли — не
здесь (следующий шаг по плану: живность поштучно и кисть для водных
растений). Столкновений камней с живностью нет. Проверено безголовым
Playwright на 41232: три объекта поставлены кнопками, манипулятор держит
камень, «Показать» наводит камеру.
