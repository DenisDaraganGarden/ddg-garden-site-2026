# Управление наклоном телефона, 27.09.2026

Локальное дополнение к Secret Garden на обложке и A French manor в галерее/полноэкранном просмотре. На сенсорном устройстве с доступным DeviceOrientation и secure context появляется «Наклон». Доступ запрашивается только после нажатия, через feature-detected requestPermission. Без этого метода подписка запускается после того же явного действия. Предполагается HTTPS на опубликованном сайте; обычный HTTP по IP компьютера не подходит. Localhost используется только для разработки на том же устройстве.

Один общий living-tilt.js принимает относительную ориентацию; devicemotion, абсолютная ориентация и отдельный компас не запрашиваются. Данные не сохраняются и не отправляются. Начальная ориентация задаёт ноль; сравнение нормалей в базисе первого положения (Z-X-Y) избегает скачка на границе ±180°. Поворот экрана преобразует оси и сбрасывает центр; полный диапазон примерно ±18°, выход ограничен ±1. Сглаживание остаётся у существующих рендереров. Отдельного цикла отрисовки нет.

Управление общее для обоих кадров. Чтение прекращается, когда все кадры на паузе, вне экрана, перекрыты диалогом, или страница скрыта. После возврата центр калибруется заново. При reduced motion кадр остаётся статичным до явного нажатия. Отказ, исключение API и отсутствие конечных показаний за 4 секунды оставляют обычное управление; интерфейс сообщает о недоступном датчике. На компьютере кнопка скрыта.

Проверено в собственном Chromium с настоящим WebGL и искусственными событиями датчика: запрос только из активного нажатия, обе оси, поворот экрана на 90°, граница ±180°, галерея/просмотр/обложка, остановка и центрирование после паузы, путь API с requestPermission и без него, отказ, исключение, отсутствие показаний, reduced motion. Пример: наклон 10° дал x≈0.55, после паузы x≈0.00005/y≈0.0018; ошибок страницы нет. Это проверка браузерной логики, не физических iPhone/Android. Прежние карты и цвет фотографий не менялись. Публикации нет.

Источники ограничений API:
- https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent
- https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent/requestPermission_static
- https://developer.mozilla.org/en-US/docs/Web/API/Device_orientation_events/Detecting_device_orientation

Дополнительно проверен установленный Playwright WebKit: мобильный viewport, подставленное разрешение, события наклона и настоящий WebGL; состояние playing, кнопка включена, ошибок нет. На desktop Chromium кнопка скрыта. Обложка 320×568 проверена визуально: новая кнопка находится в нижнем ряду и не перекрывает имя.
