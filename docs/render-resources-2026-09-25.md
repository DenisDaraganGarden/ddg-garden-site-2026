## Реализация

- `disposeModelMaterials` освобождает карты overrides, face-rule материалы,
  split/box-UV геометрии; общие исходники GLTF остаются живыми. Поздние ответы
  загрузчика не возвращают удалённые карты. Карточки SketchUp владеют своими
  wind-геометриями и материалами, не изменяя закэшированную геометрию модели.
- `sharedTextureCache`: общий Source по URL/цветовому пространству, отдельный
  Texture для UV каждого потребителя. Последний dispose удаляет запись кэша.
  Частично неудачная загрузка набора освобождает успешно загруженные карты.
- Общая ревизия WebGL-контекста перезапекает газон, грунт/опад, sky PMREM,
  отражения стекла и облачные shadow/atlas/PMREM. Облачное освещение оказалось
  отдельной потерянной картой при восстановлении на паузе; исправлено и проверено.
  Таймеры GPU сцены/облаков пересоздаются без обращения к старым query handles.
- Через 500 мс после выключения post его HDR/MSAA, bloom и AO targets переходят
  к размеру 1×1, освобождая выделенное хранилище. Включение восстанавливает
  нужный размер; быстрые переключения не вызывают лишнее освобождение.

## Проверка в настоящем Electron

Исходник установленного OUROBOROS:
`.claude/worktrees/infallible-diffie-462766`, база `34363d8`.
Electron 42.4.1, Three 0.183.2, Apple M4 Max, WebGL2/ANGLE Metal.
Отдельный профиль и копия Ростова **revision 80**, порт 41213.
Парные прогоны использовали один JSON, одну камеру «Рабочая 1» и один размер:
окно 1440×900, canvas 1088×834, DPR 1; post выключен.
Исходные модули для прогона «до» получены из HEAD; остальные файлы общие.

| Состояние | Текстуры renderer.info | Геометрии renderer.info |
|---|---:|---:|
| До, начало | 153 | 915 |
| До, после 3 hide/show | 249 | 1332 |
| После, начало | 137 | 915 |
| После, каждый из 10 hide/show и после GC | 137 | 915 |

WeakRef-трекер реальных GL handles подтвердил устойчивое плато после исправления.
До исправления три цикла даже после GC оставляли **+1280 МиБ** texture storage.

Начальный texture storage: **1261,7 → 984,3 МиБ**, экономия **277,3 МиБ**.
Все 12 групп повторяющихся URL теперь используют по одному Source/GL handle;
отдельные UV сохранены. Считались размеры выделенных textures/renderbuffers
и mipmaps: это оценка логического GPU storage, не показание физической VRAM
и не полный объём общей памяти macOS.

Два переключения native post/MSAA/AO on→off освобождают по **55,4 МиБ**
при 1088×834. Повторный прогон включал изменение окна до 1280×820 и обратно;
повторное включение отрисовалось правильно, буферы снова освобождались.

Два искусственных context lost→restored на паузе: газон, отражения и освещение
визуально восстановились. После снятия паузы GPU-time снова выдаёт измерения.
Трекер финальной проверки исключает handles прежней генерации контекста;
память между двумя восстановлениями не накапливается.
После restore счётчики Three могут быть ниже исходных: регистрация ресурсов
ленивая; это само по себе не доказательство дополнительной оптимизации.

Исходный/исправленный кадры и оба восстановления осмотрены. Ошибок страницы
и console.error в трёх завершённых прогонах нет. Ростов и окно фоторендера
в установленном приложении оставлены пользователю; его окно не перезагружалось.
Оригинальные проектные JSON и опубликованная сцена этой работой не записывались.

## Повторяемые проверки и пределы

Прошли:
`node src/materials/modelResources.check.js`,
`node src/components/effects/rendererContext.check.js`,
`node src/materials/faces.check.js`,
`node src/components/effects/renderBudget.check.js`,
ESLint изменённых модулей и `git diff --check`.
Тесты покрывают общий Source/раздельные UV, refcount, поздние/неудачные загрузки,
повтор setup/cleanup в StrictMode, владение wind-геометрией и сброс GPU queries.

Короткие замеры GPU до/после дали медианы 11,53/10,52 мс, но общий фон машины
менялся; гарантированный прирост FPS из них не выводится. Установленный результат —
освобождение памяти и устойчивость проверенных переходов с сохранением картинки.
Вода, ночная сцена с фонарями, физический телефон и долгие переходы между
разными большими проектами требуют отдельной проверки. Библиотечный GLTF-кэш
по URL не менялся. Полный build/smoke не запускался.

Изменения оставлены **незакоммиченными** в активном чекауте. Параллельные правки
фоторендера сохранены, включая общий `ScenePostProcessing.jsx`. Push не было.
Временные копии данных, профили, диагностические скрипты/кадры и сервер удалены.
