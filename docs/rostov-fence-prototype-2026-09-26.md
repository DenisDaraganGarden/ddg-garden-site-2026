# Ростов: процедурная ограда по периметру

Прототип для просмотра, 26 сентября 2026. Исходник — живой локальный проект
`~/Ouroboros/projects/rostov.json`, ревизия 87. Оригинал не записывался; его
SHA-256 после просмотра начинается с `ada7a14509e6b1c8`.

В `src/topiary/TopiaryFence.jsx` металлические секции собираются вдоль линии
формы «Стриженые формы». Опоры ставятся не дальше 2,4 м друг от друга, панели
между ними прямые. Есть сетка 2D (ячейка около 200 × 50 мм), мелкая сетка 358
(около 76 × 12,7 мм) и частокол с острыми наконечниками. Выключатель
«Плавный сплайн» сглаживает путь, для углов участка он оставлен выключенным.
Зелёная форма может показываться поверх той же линии или быть скрыта для
осмотра металла.

Путь прототипа получен по красной границе сохранённого генплана с небольшим
отступом внутрь; контрольные точки в мировых координатах X/Z:

```
(-11.628, -20.783) → (13.985, 19.746) → (-9.027, 36.988)
→ (-41.330, -3.961) → начало
```

Основание Y = 1,38 м по сетке высот участка, высота ограды = 2,3 м.
Сегмент над въездом пока не разорван: положение ворот нужно уточнить по
схеме доступа. Это визуальная примерка, а не рабочая документация по
фундаментам, калиткам и монтажу.

Для просмотра создана отдельная копия проекта в ignored-каталоге
`.claude/fence-preview-data/` этого воркдерева. Она открыта на
`http://localhost:41231/home/edit?project=rostov`; в копии скрыта группа
SketchUp `ЗАБОР#1` (узел 157), чтобы старое ограждение не перекрывало новое.
Добавлены рабочие камеры «Ограда · 2D крупно», «Ограда · 358 крупно»,
«Ограда · частокол» и «Ограда · стрижка». Оригинальные камеры оставлены.
Проверены крупные кадры каждой конструкции и общий вид в редакторе.
