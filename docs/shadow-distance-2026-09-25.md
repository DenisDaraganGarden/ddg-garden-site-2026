# Тени без преждевременного обрезания — 25 сентября 2026

Исправлен разрыв теней в двухкаскадном режиме CSM. Дистанция в настройках
остаётся 160 м, размеры и количество карт не повышены.

## Причина и решение

CSM переносил дальний источник света за дальнюю грань видимого объёма, но
теневая камера имела фиксированную глубину `maxFar + 80` (240 м). При широком
ракурсе и косом солнце часть видимой модели/приёмников находилась дальше этой
плоскости. Тень обрывалась внутри разрешённой дистанции — это не обычный LOD.

`csmDepthBounds.js` после обновления каскадов измеряет их объём вдоль светового
луча. Учитывает интервал смешивания CSM и прежний запас для объектов перед
каскадом. Свет сдвигается только вдоль луча; XY-проекция, плотность texels,
число и размеры карт сохранены. Глубина округляется вверх до метра.
Физический contact offset пересчитывается для полученной глубины.
Адаптер также передаёт смену mapSize в шаг привязки CSM к texel.

На воспроизведённом ракурсе вместо двух глубин по 240 м получены **83 и 378 м**.
Прямоугольный разрыв тени за стеной исчез. Простая проба с far=800 тоже
убирала разрыв и подтвердила причину; в продукт вошёл расчёт по объёму.

## Проверка

Настоящий Electron 42.4.1, Three 0.183.2, M4 Max/ANGLE Metal.
Изолированный профиль, порт 41213, копия Ростова revision 87; оригинал не
записывался. Canvas 1088×834, DPR 1. Проверены ракурс над участком,
противоположный ракурс с низким солнцем и генплан с высоты 300 м.
Изображения осмотрены; ошибок страницы/консоли не было.

Для A/B/B/A облака выключены только в тестовой копии. Старое отсечение
временно возвращалось через диагностический callback; камера и освещение
фиксированы. По 30 GPU-опросов в каждом проходе после прогрева.

| Показатель | Старое отсечение | Исправление |
|---|---:|---:|
| Среднее время кадра, два прохода | 9,68 / 9,80 мс | 10,19 / 10,16 мс |
| Медиана GPU, два прохода | 5,02 / 5,87 мс | 5,77 / 5,29 мс |
| Геометрии / текстуры renderer.info | 912 / 131 | 912 / 131 |
| Теневые карты | 2 × 2048² | 2 × 2048² |

Цена полного кадра в этой пробе около 0,4–0,5 мс: больше правильных теневых
треугольников попадает в растеризацию. GPU-замеры колеблются; прирост FPS не
заявляется. Диагностическое возвращение старого отсечения добавляет ещё один
вызов позиционирования CSM, поэтому это оценка, а не точный CPU-бенчмарк.

Автотест проверяет реальную проекцию всех углов каскадов и зоны смешивания
по глубине: широкая камера, низкое солнце, портрет и генплан; отдельно —
неизменный физический bias и mapSize. Прошли `check:render-resources`,
`check:render-core`, `check:water`. Регрессии ресурсов/контекста/теней добавлены
в GitHub CI. Полные `npm run lint` и `npm run build` прошли на отдельном
экспорте точного состава коммита. Остались предупреждения в неизменённых
CoastRocksPBR/three-globe/WebGPU stub и о крупных JS chunks.
Полный smoke не запускался. Исправление однотеневого режима телефона не входило в эту работу;
физическое мобильное устройство здесь не проверялось.

Предыдущие [GPU-исправления](render-resources-2026-09-25.md) входят в тот же
набор изменений. Авторские JSON, настройки камер и опубликованная сцена
сохранены. Фоторендер из параллельной задачи остаётся отдельно в рабочем
чекауте и не включается в этот коммит.
