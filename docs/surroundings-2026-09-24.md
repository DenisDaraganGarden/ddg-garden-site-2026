# Окружение участка по адресу — решение и этапы (2026-09-24)

> Просьба Дениса: «вписать проект в 3D-карту: ввожу адрес — появляется окружение
> с дорогами и зданиями (с высотами, если их кто-то смоделил); границы карты
> можно сузить или расширить; агент может окружение домоделить». Не Google, а
> лучшая карта с гибкими настройками для России. Только для проектов «Участок».

## Почему OpenStreetMap, а не Google, Яндекс, 2ГИС или Cesium

| Источник | Россия | Можно строить свою сцену | Итог |
|---|---|---|---|
| **OpenStreetMap** (Overpass, API OSM) | одно из самых подробных сообществ: этажность (`building:levels`) у 70–98 % домов в центре Ростова, ширина и полосы дорог, заборы, деревья | да, лицензия ODbL — нужна подпись «© участники OpenStreetMap» | **основа** |
| Рельеф Terrarium (AWS Open Data) | весь мир, в России — SRTM, шаг ~30 м | да | склоны к реке видны, бордюры — нет |
| Google Photorealistic 3D | российских городов нет, оплата из России не проходит | только внутри их просмотрщика | нет |
| Яндекс, 2ГИС | лучшие коммерческие 3D-данные по России | условия запрещают забирать геометрию в свою сцену; из сети Дениса не ответили | нет |
| Cesium ion (OSM Buildings) | те же дома OSM | через их токен, коммерческое — платно | берём OSM напрямую |

OSM — векторные данные, а не готовая сетка: движок строит окружение сам, в своём
стиле (белый макет), и любой дом можно поправить руками или агентом.

## Как устроено (этап 1 — сделан)

- **Панель «Окружение»** (Сцена → Ландшафт, только в «Участке»): адрес или
  координаты «47.2225, 39.7188» → мини-карта (схема OSM / спутник Esri), точку
  можно тянуть; радиус 100–1500 м; «Загрузить / Обновить окружение».
- **Сервер** (`scripts/surroundings.mjs`, маршруты `/__geo/search`,
  `/__surroundings/<проект>`): Overpass лесенкой по четырём серверам, запасной
  путь — API самого OSM (из сети Дениса Overpass часто рвёт TLS; так загрузка
  занимает 15–30 с, а не 5 минут); рельеф — тайлы Terrarium.
- **Данные** — файл проекта `~/Ouroboros/projects/<id>/surroundings.json`, не в
  git и не на сайте (адрес заказчика). Одна запись — одна строка: дом
  `{id, kind, ring, holes?, height, min?, levels?, from, label?}` (`from`:
  `height` — высота из OSM, `levels` — этажи × 3 м + 1 м, `guess` — оценка по
  типу здания), дорога `{id, kind, width, line}`, площадь `{id, kind, ring}`
  (вода, лес, зелень, поля, спорт, песок, мощение), линия `{id, kind, line}`
  (реки, рельсы, заборы, стены, изгороди), деревья `[x, z, h?]`, рельеф — сетка
  129×129 относительно высоты точки. Метры сцены: +X восток, −Z север.
- **Сцена** (`src/surroundings/`): земля — круг с рельефом, дороги и площади
  нарисованы на ней картинкой 2048²; дома — коробки одним вызовом отрисовки;
  заборы — стенки; деревья и лес — макетные «шары» (лес засевается через 7 м).
  В круге участка (по умолчанию 15 м) чужих домов нет и земля ровная, дальше
  плавно уходит в рельеф. Первая загрузка выключает «Плоскость».
- **Совмещение с моделью**: точка карты садится на модель SketchUp (её
  середину у земли) со сдвигом X/Z в осях модели; поворот — общий север участка
  (`northAngle`, `siteNorth` в `src/planting/north.js`): стрелка «С», генплан и
  окружение смотрят в одну сторону. Подогнать север по дорогам карты — значит
  откалибровать солнце и тени будущего этапа «Настоящее солнце».

## Агент «домоделивает»

Файл окружения правится как текст. Запись с пометкой переживает новую загрузку
(`mergeAuthored`): `"edited": true` — поправленная (высота, контур), `"custom":
true` — дорисованная (id `custom-…`), `"hidden": true` — спрятанная. После правки:
`node scripts/surroundings.mjs <проект> --touch` — открытый редактор перечитает
файл, когда окно вернётся в фокус. Загрузить заново из командной строки:
`node scripts/surroundings.mjs <проект> [--radius 400] [--at 47.2225,39.7188]`.

## Дальше — предложения (решает Денис)

1. **Граница участка по кадастровому номеру** (НСПД Росреестра): контур
   участка вместо круга. Сайт требует российский корневой сертификат и часто
   закрыт для зарубежных адресов — проверить из сети Дениса.
2. **Щелчок по дому**: спрятать, поправить этажность — сейчас это делает агент в файле.
3. **Больше домов там, где OSM пуст** (частный сектор, дачи): Overture Maps —
   OSM плюс дома, найденные по снимкам (Microsoft, Google).
4. **Спутник на земле** вместо схемы — как подложка для презентации.
5. **Крыши** (`roof:shape`), части зданий, тротуары и бордюры, разметка.
6. **Автосовмещение**: север и сдвиг по совпадению заборов модели с заборами OSM.
7. **Выгрузка окружения в SketchUp** (.glb/.dae), чтобы контекст был и там.
