# Детали движка

Деталь — настроенный вариант одного объекта: три вида травы, пять кустов, своя
вода. Движок процедурный, поэтому вариант — это просто значения параметров
объекта под именем; из деталей собирается новый проект.

```
{ "id": "…", "name": "…", "node": "greenery/grass", "object": "Трава",
  "created": "…", "updated": "…", "values": { …ключи только этого объекта… } }
```

Сохраняются из редактора: ПКМ по объекту в сцене → «Детали объекта…», или ⌘K →
«Детали объекта». Что входит в деталь, решает сам редактор — ключи берутся из
его каталога контролов для этого узла, второго списка не заводится.

Детали общие для всех проектов и на сайт не уезжают. Полный перечень параметров
с пределами — `docs/engine-parameters.md`.
