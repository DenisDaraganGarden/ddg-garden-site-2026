# Проекты движка

**Где лежат.** Не здесь, а в доме движка — `~/Ouroboros/projects/` (переопределяется
переменной `DDG_PROJECTS_DIR`): один на все копии репозитория и вне git, потому что
в проектах модели заказчиков. Эта папка в репозитории — только описание. Проекты,
оставшиеся в папках чекаутов и воркдеревьев, переносит
`node scripts/migrate-projects-home.mjs` (источники не трогает, повтор безопасен).

Один файл — один проект: числа сцены и камеры. Ассеты (модели, текстуры, небо,
звук) общие для всех проектов, лежат в `public/` и сюда не копируются — движок
процедурный, форму он считает из этих чисел.

```
{ "id": "…", "name": "…", "engine": "1.4.0", "created": "…", "updated": "…",
  "settings": { …тот же набор ключей, что у сцены сайта… } }
```

Создаются и правятся из главного меню движка — `/engine` на локальном сервере.
Редактор открывает проект по адресу `/home/edit?project=<id>` и пишет туда же.
Рядом с записью лежит миниатюра `<id>.webp` — кадр вьюпорта, редактор снимает
его сам (после сборки сцены и не чаще раза в несколько секунд при правках).
В самом JSON картинки нет: агенту, читающему числа, она бы только мешала.

Сайт в этой папке не живёт. Его сцена — `src/features/home-scene/data/publishedHomeSceneSettings.js`,
она публикуется кнопкой «В проект» из редактора без `?project=`. Любой проект
может стать этой сценой: внутри проекта «На заглавную» пишет его сцену в тот же
файл, «На сайт» — и отправляет на GitHub; в меню проектов то же в контекстном
меню карточки. Рядом `publishedHomeSceneSource.json` помнит, какой проект стоит
на заглавной. Прежняя сцена сайта сохранена проектом `sayt-osnovnaya-scena`.

Заводские значения («заводской берег») собираются из модулей настроек:
`src/terrain/settings.js`, `src/plants/settings.js`,
`src/components/effects/water/seaSettings.js`, `src/shore/settings.js`,
`src/tanker/settings.js`, `src/features/home-scene/lib/painterlyCloudSettings.js`,
`src/components/effects/renderQualitySettings.js`. Это же список того, что
движок умеет: правка там меняет и заводской проект, и список публикуемых ключей.
